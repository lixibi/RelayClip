# Windows Client Plan

RelayClip Windows 客户端后续按效率工具方向开发，保持轻量、本地优先、快速可用。

## 产品定位

Windows 客户端不是重型多设备同步平台，也不做配对码、P2P 大文件或复杂账号体系。它连接同一个自建 RelayClip Server，实现本机剪贴板历史和按需远程共享。

## 首版目标

- 托盘常驻。
- 本地剪贴板历史。
- 快捷键呼出浮动面板。
- 点击条目复制。
- 文本和图片缩略图显示。
- 手动发送当前剪贴板到远程。
- 手动发送单条历史记录到远程。
- 同步远程列表。
- 设置服务器地址。
- 未配置服务器时显示新手向导。

## 默认策略

- 默认只记录本机剪贴板。
- 默认不自动上传。
- 自动上传作为设置开关。
- 远程同步通过同一个自建服务器完成。
- 图片缩略图优先走本地缓存。

## 推荐界面

- 系统托盘菜单只放高频入口：浮动面板、同步、设置、退出。
- 浮动面板用于主要操作：搜索、分类、复制、发送到远程。
- 主设置窗口只放配置项：服务器地址、快捷键、自动上传、缓存管理。

## 技术预研

候选方向：

- Tauri + Rust：体积小，托盘和跨平台能力好。
- Wails + Go：服务端同为 Go，代码风格统一。
- Native WinUI 3：Windows 原生体验更好，但开发成本更高。

首轮建议优先评估 Wails 和 Tauri，重点看：

- 托盘常驻稳定性。
- 全局快捷键。
- 剪贴板监听。
- 图片读写和缩略图缓存。
- 安装包体积。
- Windows 10/11 兼容性。

## 非目标

- 不做安卓客户端。
- 不做配对码。
- 不做 P2P 大文件。
- 不做复杂账号系统。
- 不做多服务器切换。

## 验收标准

- 离线打开可立即看到本地历史。
- 复制、搜索、发送到远程操作足够快。
- 没有服务器地址时能引导用户部署或填写地址。
- 服务端不可用时不影响本地历史使用。
- 图片缩略图不会每次都重新拉远程资源。
